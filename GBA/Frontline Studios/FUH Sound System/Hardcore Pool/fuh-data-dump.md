# FUH Sound System — data dump

These are the sound-data tables of the two FUH games analysed in *FUH Sound System — technical reference*.
For each game the dump gives every module (music and SFX banks), every instrument, the order list with
pattern indices and position jumps, every tune with its entry order, loop point and length, effect usage,
and a count of events whose meaning changes because of engine quirks (reference §11.1).

Generated by `fuhdump.py`. Decoded patterns (`*_patterns/moduleN_*.txt`) and every instrument as a WAV
(`*_wav/`, written at 16 726 Hz, the rate at period 3840) are in `GBAAudioLab/FUH/Claude outputs/`.

Conventions:

* **Effect numbers** are FUH's own (`(flags >> 2) & 31`). The mapping to XM is in reference §9.3.
* **Note names** convert the stored XM linear period back to an XM note. C-4 is period 4608, which plays a
  sample at 8 363 Hz. A suffix such as `(-11)` means 11/64 of a semitone below that note.
* **Tunes** are listed by entry order. "No call site" means the tune is only reached as a jump target and no
  game code starts it.
